# Maze Solving Car

## Overview

This project implements a maze-solving robot using an STM32F303 microcontroller.

The car navigates through a maze using sensors and makes movement decisions based on the implemented navigation algorithm.

---

## Hardware

- STM32F303RE
- DC Motors
- Motor Driver
- Distance Sensors
- MPU
- Power Supply

---

## Features

- Motor control using PWM
- Sensor data acquisition
- Maze navigation algorithm
- Obstacle detection
- Real-time movement control

---

## Development Environment

- STM32CubeIDE
- STM32 HAL Library
